# 验证记录

验证日期：2026-09-27。以下为程序验证，不代表物体识别实验成绩。

## 已完成

- Windows / Python 3.12.13，torch 2.11.0+cu128、torchvision 0.26.0+cu128；CUDA 识别 RTX 5060。
- 30 项 unittest 全部通过：分组划分和重复条件隔离、位置 buffer、源文件变化、光流单位/时间、混合后端拒绝、几何刚体变换不变性、无效触点/帧屏蔽、图节点置换、空间边作用、各分支反向梯度、基线与消融。
- 使用真实采集目录 `dataset_underactuated/runs/20260927_054834/tomato_soup_can/episode_0000` 生成 Farneback 光流和夹爪系几何缓存；光流为 `[3,31,2,128,96]`，每对间隔 0.02 秒；几何为 `[32,3,12]` 和 `[32,3,3,5]`。
- Farneback 预处理的 Windows 双进程启动通过。
- 上述真实样本通过默认 ResNet18 + 动态编码 + 对齐 + 图融合的 GPU 前向和反向检查，123 个参数张量获得有限梯度；没有执行参数优化。
- 临时两类合成数据通过建立索引、分组划分、连续光流、MuJoCo 前向运动学、CUDA/AMP 训练一轮、断点续训一轮、读取最佳模型评估的完整流程。
- 同一完整流程也通过 Windows DataLoader `num_workers=2`；合成数据在临时目录自动清理。
